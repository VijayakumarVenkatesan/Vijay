### 15. Path Sum — LC 112
**Description:** Determine whether there exists a root-to-leaf path whose values add up to `targetSum`.

**Input:**
```text
      5
     / \
    4   8
   /   / \
  11   13 4
 /  \
7    2

targetSum = 22
```

**Expected Output:**
```text
true
```

Because:

`5 → 4 → 11 → 2 = 22`

---

## 🎯 Your Tree Practice Order

Don't randomly solve these. Follow this progression:

```text
                TREES
                  │
        ┌─────────┴─────────┐
        ↓                   ↓
     Binary Tree           BST
        │                   │
   Traversals          Search / Insert
        │                   │
   Height / Depth       Validate BST
        │                   │
   DFS / BFS             Inorder
        │                   │
   Path Problems        Kth Smallest
        │                   │
   LCA / Diameter          LCA
        │
   Construction
        │
   Advanced
```

### ⭐ Highest-priority problems

If your goal is **interview preparation**, master these first:

| # | Problem | Main Pattern |
|---|---|---|
| 1 | Maximum Depth | DFS / Recursion |
| 2 | Inorder Traversal | DFS |
| 3 | Level Order | BFS / Queue |
| 4 | Diameter | DFS + Height |
| 5 | Balanced Tree | DFS + Height |
| 6 | Path Sum | DFS |
| 7 | LCA | DFS |
| 8 | Maximum Path Sum | DFS |
| 9 | Validate BST | Inorder / Bounds |
| 10 | Kth Smallest BST | Inorder |
| 11 | Construct Tree | Recursion + HashMap |
| 12 | Serialize/Deserialize | DFS/BFS |

**Best strategy:** Don't just memorize solutions. For each problem, identify **what information the recursive function needs to return**. That's the key to becoming strong at Tree problems.
