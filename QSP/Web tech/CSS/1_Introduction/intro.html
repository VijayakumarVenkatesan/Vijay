CSS Introduction

3 Types of CSS

Inline CSS

The styles written for the tags in that same line inside the opening tag

Internal CSS

The styles for the HTML written inside the style tag in the head section

External CSS

The style written in the seperate css file which is linked using link tag to the HTML

CSS Selectors

Universal selector

Styles inside this will apply for entire HTML

Class selector

Select the elements by class name, prefixed with fullstop

Id selector

Select the elements by unique id, prefixed with hash

Tag selector

Select the tag by the tag names
