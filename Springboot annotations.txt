🔹 1. Core Spring (commonly used in Spring Boot)

@Component
	Used to mark class as a spring managed bean.

@Service
	Specialized component used for business logic.

@Repository
	Used for persistence layer.

@Controller
	Handles web request which returns the view.

@RestController
	Controller which returns the JSON instead of views.

@Autowired
	Inject beans automatically.

@Qualifier
	Select beans to inject when more than one beans in same type.

@Primary
	Marks the bean as default if more than one bean are in same type.

@Configuration
	Defines the bean manually.

@Bean
	Mention the method will return bean.

@Value
	Inject values from application.properties.

@PropertySource

@Profile
	Active only beans under a profile.

@Scope

@Lazy
